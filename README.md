# 🎯 Lente Crítica

Plataforma de Letramento Midiático e Informacional

## 📚 Sobre

Projeto para ensinar alunos do 6º ano ao 3º EM a:
- Verificar informações antes de compartilhar
- Analisar fontes de forma crítica
- Identificar desinformação
- Pensar criticamente sobre conteúdo online

## 📊 O que tem aqui

- 180 desafios divididos por série
- Rubricas de avaliação
- Alinhamento com UNESCO MIL e BNCC
- Guia para professores

## 🎮 Como usar

1. Escolha um desafio da lista
2. Analise o conteúdo em 10 minutos
3. Responda as perguntas
4. Receba feedback
