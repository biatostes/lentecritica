# 🎯 Lente Crítica

> Plataforma de Letramento Midiático e Informacional para Educação Básica

[![UNESCO MIL](https://img.shields.io/badge/UNESCO-MIL%20Alliance-blue)](https://www.unesco.org/mil4teachers)
[![BNCC](https://img.shields.io/badge/BNCC-Brasil-green)](https://basenacionalcomum.mec.gov.br)

## 📚 Sobre

O **Lente Crítica** é uma plataforma educacional que desenvolve habilidades de verificação, análise crítica e uso ético da informação em alunos do **6º ano ao 3º ano do Ensino Médio**.

### 🎯 Objetivo

Ensinar alunos a:
- ✅ Verificar informações antes de compartilhar
- ✅ Analisar fontes de forma crítica
- ✅ Identificar desinformação e deepfakes
- ✅ Pensar criticamente sobre conteúdo online
- ✅ Usar informação de forma ética e responsável

### 📚 Alinhamento

- **UNESCO MIL Alliance**: Competências de acesso, avaliação, uso e criação de informação
- **BNCC**: Habilidades de Língua Portuguesa, Matemática, Ciências e Ciências Humanas

---

## 🎮 Funcionalidades

### Para Alunos

- **180 desafios** divididos por série (6º ano - 3º EM)
- **Tipos variados**: manchetes, posts, imagens, gráficos, vídeos, áudios, deepfakes
- **Feedback imediato** após cada desafio
- **Sistema de badges** para gamificação
- **Acompanhamento de progresso** por habilidade

### Para Professores

- **Painel de controle** com estatísticas da turma
- **Atribuição de atividades** personalizadas
- **Relatórios detalhados** por aluno e por habilidade
- **Exportação de dados** em CSV
- **Rubricas de avaliação** alinhadas à BNCC

---

## 📊 Estrutura de Desafios

### 6º Ano (30 desafios)
- Fato vs. Opinião
- Autoria e Fonte
- Imagem e Contexto
- Propósito e Intenção

### 7º Ano (30 desafios)
- Viés e Estereótipo
- Dados e Estatísticas
- Causa e Efeito
- Sensacionalismo

### 8º Ano (30 desafios)
- Deepfake (vídeo e áudio)
- Manipulação de Gráficos
- Seleção de Dados
- Falácias Lógicas

### 9º Ano (30 desafios)
- Algoritmos e Bolhas de Filtro
- Privacidade e Dados
- Redes de Desinformação
- Ética da Informação

### Ensino Médio (60 desafios)
- Desinformação Científica
- Política e Eleições
- IA Generativa
- Mudança Climática
- Saúde Pública
- Direitos Humanos

## 📁 Como Usar Este Repositório

### Para Professores

1. **Clone ou baixe** este repositório
2. **Acesse** a pasta `docs/` para ver a documentação
3. **Use** os arquivos JSON da pasta `data/` para importar em sua plataforma
4. **Consulte** `RUBRICAS.md` para avaliação
5. **Siga** `GUIDE_TEACHERS.md` para implementação em sala

### Para Desenvolvedores

1. **Fork** este repositório
2. **Use** os dados JSON para alimentar sua aplicação
3. **Consulte** a documentação em `docs/`
4. **Contribua** com novos desafios ou melhorias

### Para Pesquisadores

1. **Referencie** este projeto em publicações
2. **Use** os dados para pesquisas em MIL
3. **Colabore** com novas categorias de desafios
